# PLC, metrics and MongoDB cookbook

Start with one runtime client on your app server. Edge supplies its connection details and credentials when the app is installed:

```js
const { createRuntimeClient } = require('./sdk');
const box = createRuntimeClient();
```

Add the capabilities used below to `metadata.orenda.capabilities` in `orenda-app.json`, then request marketplace review. The Box administrator must also approve each grant when installing or updating. Use `box.context()` to inspect what was granted; do not hide a declined permission behind a generic connection error. These core APIs work without `network:outbound` because the Box provides them through its authenticated runtime facade.

## Read current PLC values

Requires `plc:read`. Discover configured names before reading them:

```js
const tags = await box.listPlcTags();
const names = tags.slice(0, 100).map(tag => tag.name);
const readings = names.length ? await box.readPlcTags(names) : { data: [] };
```

The result is the existing collector’s `{ data }` response. Show an empty state when no tags are configured. Let the Box administrator configure devices through Edge Console/PLC Config UI. This SDK does not invent another PLC configuration or driver layer. Bundle reads and avoid polling faster than your application needs.

## Show a chart from Prometheus

Requires `prometheus:read`. The Box’s collector exports the existing `plc_tag_value` metric with `tag` and `device` labels. Discover metrics to avoid hard-coding service-specific names unnecessarily:

```js
const available = await box.metrics.metricNames('plc_');
const health = await box.metrics.query('up{job="orenda-plc-collector"}');
const end = Date.now() / 1000;
const history = await box.metrics.queryRange('plc_tag_value', {
  start: end - 3600,
  end,
  step: 60
});
for (const series of history.data.result) {
  // series.metric identifies the tag/device. Each value is [epochSeconds, stringValue].
  console.log(series.metric, series.values.length);
}
```

Use narrower label selectors or aggregation for large systems. Render a loading state while querying, an empty state when there is no history, and a retry action for transient failures. The facade uses Prometheus’s existing [HTTP query API](https://prometheus.io/docs/prometheus/2.55/querying/api/) and preserves its response format. It grants read access to Box metrics, without exposing lifecycle/reload endpoints.

## Store app data in MongoDB

Requires `mongodb:read` and `mongodb:write` for this full example. Edge chooses the app’s private database in the existing MongoDB service. You provide only a collection name:

```js
const notes = box.mongo.collection('shift_notes');

const { insertedId } = await notes.insertOne({
  text: 'Inspect line 2 before the next shift',
  status: 'open',
  createdAt: new Date().toISOString()
});

const { documents } = await notes.find(
  { status: 'open' },
  { limit: 20, sort: { createdAt: -1 } }
);

const { document } = await notes.get(insertedId);
const { _id, ...fields } = document;
await notes.replaceOne(_id, { ...fields, status: 'resolved' });
await notes.deleteOne(_id);
```

`replaceOne` replaces the entire document, not a partial patch; read and retain any fields you need. `_id` is generated by the Box and immutable. Use ISO strings for dates. This JSON facade supports ordinary documents without requiring BSON/driver dependencies in the app. It does not accept direct driver commands, a database argument, aggregation, index creation or Mongo URLs. The same collection name in two apps is stored in different databases.

For a read-only viewer, request only `mongodb:read`. Check the current Edge user’s roles in your app before allowing writes; the app’s runtime credential grants a service capability, not user authorization. A background job can use the app’s approved capabilities without storing a human password.

## Filters, limits and errors

```js
await notes.find({
  $and: [
    { status: { $in: ['open', 'assigned'] } },
    { priority: { $gte: 2 } }
  ]
}, { limit: 50, skip: 0 });
```

Supported comparisons are `$eq`, `$ne`, `$gt`, `$gte`, `$lt`, `$lte`, `$in`, `$nin`, and `$exists`, combined with `$and`/`$or`. Sorting accepts up to five fields with direction `1` or `-1`. Collection names use letters/digits/underscores/hyphens, start with a letter, and are at most 64 characters. `system` prefixes and operator/prototype keys are reserved.

Catch errors using `error.status`: explain `403` as a missing approved permission, `413` as a document/storage limit, and `429` as a temporary request limit. Back off on `429`/`502` rather than retrying in a tight loop. Documents are limited to 64 KiB and each app to 10,000 documents, 32 collections and 128 MiB. A find returns at most 100 documents. These limits keep a small Box responsive for other installed software.

Core MongoDB remains the DevicePlatform-provisioned service. The Edge host uses MongoDB’s official Node driver compatible with the existing 4.4 server; the SDK does not add another MongoDB container or distribute global database credentials. [Driver compatibility guidance](https://www.mongodb.com/docs/drivers/node/current/reference/upgrade/) explains version requirements.
